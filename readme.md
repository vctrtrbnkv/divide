# Система деления счета в ресторане

Этот проект представляет собой приложение для деления счета в ресторане между несколькими гостями. Оно позволяет пользователям легко распределять сумму счета, учитывая позиции меню и количество людей. Приложение поддерживает добавление и редактирование информации о гостях, а также управление количеством заказанных позиций.

## Описание

Приложение предназначено для ресторанов, кафе или любых других заведений, где несколько гостей могут делить счет. Основные функции приложения включают:

- Просмотр и редактирование счета.
- Деление позиций счета между гостями.
- Подсчет общей суммы для каждого гостя.
- Возможность добавления новых гостей и редактирования их информации.
- Управление количеством позиций, заказанных каждым гостем.

## Функции

- Добавление/удаление гостей: Управление списком гостей с возможностью добавления новых.
- Редактирование информации о госте: Возможность изменить имя, телефон и список заказанных позиций для каждого гостя.
- Деление счета: Распределение позиций меню между гостями и пересчет суммы для каждого.

## Технологический стек

- React: Библиотека для построения пользовательского интерфейса.
- RTK Query: Для управления состоянием приложения.
- React Router: Для организации маршрутизации в приложении.
- Styled-components: Для стилизации компонентов.
- TypeScript: Для строгой типизации кода.

## Установка и запуск

### Пререквизиты

Для работы с этим проектом необходимо установить:

- **Node.js** (v14 и выше)
- **npm**
- **JSON Server** для симуляции бэкенда (используется для хранения данных о счетах и гостях)

### Установка

1. Клонируйте репозиторий
   git clone https://github.com/vctrtrbnkv/divide.git

2. Перейдите в директорию проекта

3. Установите зависимости
   npm install

4. Запуск в режиме разработки
   npm run dev
   npx json-server --watch db.json
